# 通用字典配置功能使用流程说明

## 1. 入口与页面结构
- 入口：系统管理 > 通用字典配置
- 页面采用三段式布局：左侧为字典类目导航，中间为明细项批量维护区，右侧为操作与统计信息。
- 支持响应式布局，适配主流PC浏览器。

## 2. 类目管理
- 左侧"字典类目"面板支持类目的新增、编辑、删除。
- 点击"新建类目"弹出弹窗，填写基础信息（名称、编码、描述、状态）。
- 类目支持多场景复用，编码需唯一。

## 3. 扩展字段管理
- 类目弹窗内"扩展字段"Tab支持动态维护扩展字段schema。
- 可一行一行地增删改扩展字段（字段编码、名称、类型、默认值、必填、排序等），无需弹窗。
- 所有变更实时反映在表格，保存类目时同步保存扩展字段schema。
- 支持多类型（文本、数字、日期、布尔），支持排序和必填校验。

## 4. 明细项批量维护
- 明细表格支持批量新增、编辑、删除明细项。
- 明细项字段包括：编码、名称、排序、默认、状态，以及动态扩展字段（根据类目schema自动生成列）。
- 明细表格顶部和底部均有"新建明细"按钮，点击可在表格内新增一行可编辑明细。
- 每行可直接编辑所有字段，扩展字段以多列形式展示，编辑时为输入框，保存时自动组装为JSON。
- 支持多行同时编辑，批量保存、批量删除（多选框操作）。
- 所有操作均在表格内完成，无需弹窗。

## 5. 典型操作流程
1. 进入"通用字典配置"页面。
2. 新建或选择一个字典类目。
3. 在类目弹窗的"扩展字段"Tab中，按需增删改扩展字段，保存类目。
4. 在明细表格内，点击"新建明细"按钮，批量录入明细项及其扩展字段值。
5. 可随时批量保存、批量删除明细项。
6. 支持随时切换类目，明细区自动联动刷新。

## 6. 交互细节与注意事项
- 扩展字段schema变更后，明细表格扩展字段列自动同步。
- 明细项的扩展字段值以JSON存储，界面自动解析为多列展示。
- 所有表格操作均支持键盘输入、Tab切换、回车保存。
- 支持数据校验（如编码唯一、必填项校验等）。
- 页面美观、交互友好，按钮均为icon+文字组合，支持hover高亮。
