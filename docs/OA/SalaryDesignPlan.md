我们正在设计一个薪酬计算方案，该方案需要涵盖以下几个收入部分：

1. 基本工资

2. 绩效工资

3. 项目提成（、促成包括商机提供销售、项目参与等）
    人员所在部门参与提成-项目毛利润的50%中，划出 **20%作为部门储备金**（存入部门账户）
    个人参与提成-设定项目个人提成比例，作为员工的收入
    注:部门员工累加的提成比例或金额<=划拨给部门的
4. 部门分红（年度，且部门业绩达标和公司净利润为正为前提）

同时，公司规定将项目毛利润的50%用于项目参与的部门及人员的分红（项目提成），剩下的作为公司留存。

下面我们详细设计薪酬计算方案：

一、基本工资

- 每个员工根据其岗位级别有固定的基本工资，如非高管员工基本工资1W。

二、绩效工资

- 绩效工资根据岗位职责的绩效评估指标确定。

- 销售岗位：完成销售目标即可拿满绩效，未完成则绩效为0。

- 研发/普通职能岗：根据工作职责的完成度和工作表现评估，绩效工资 = 绩效基数 × 绩效系数（0~1.5）。

- 假设非高管员工绩效基数为2W。

三、项目提成（个人参与项目的直接奖励）

- 项目提成来源于项目毛利润的50%。

- 项目提成分配规则：

a. 商机提供奖励：固定金额（如500元）或按比例。

b. 促成销售奖励：按合同金额的去掉成本后的毛利润的一定比例（如10%）。

c. 项目参与奖励：根据参与项目的角色分配项目提成总额（即50%的毛利润）的相应比例。

- 项目角色分配表：每个项目在立项时根据产品毛利分配指导表设定各角色的提成比例或固定金额。

- 一个员工可能参与多个角色，则累加其所有角色的提成。

- 项目提成在项目回款后3个月内发放(金额大时分批发放)

- 举例：某IDC项目，毛利润100万。

1. 项目提成池 = 100万 * 50% = 50万。

2. 按部门分配：假设销售部（主导）分60%即30万，研发部分30%即15万，运维部分10%即5万。

3. 各部门内部分配：

销售部：30万，部门留存20%（6万），剩余24万分配给员工（比如员工A分12万，员工B分8万，员工C分4万）。

研发部：15万，留存20%（3万），剩余12万分配（员工D分10万，员工E分2万）。

运维部：5万，留存20%（1万），剩余4万分配（员工F分4万）。


- 员工每月收入 = 基本工资 + 绩效工资（按月发放）+ 项目当月回款金额*提成比例


四、项目提成分配流程：

1. 计算项目提成池 = 项目毛利润 * 50%

2. 将项目提成池按预设规则（如项目角色对应的部门权重）分配给各个参与的部门（部门提成）

- 例如：售前角色属于销售部，商务角色属于市场部，研发角色属于研发部，等等。

- 每个角色的贡献权重可以映射到其所属部门，从而计算出每个部门应得的提成比例。

- 或者，也可以由项目经理在立项时确定各部门的贡献比例，经审批后作为分配依据。

3. 每个部门获得部门提成金额后，部门负责人需要制定内部分配方案（在项目结束后一定时间内），将部门提成分配给参与项目的员工个人，并可以留存一定比例进入部门储备金账户。

    部门内部分配示例：
    
    部门提成金额 = 10万元
    
    部门内部分配规则：80%分配给员工个人，20%留存部门储备金账户(具体根据项目分配配置)

    则：8万元分配给员工个人（由部门负责人根据员工贡献分配），2万元进入部门储备金。

4. 员工个人从项目中获得的提成收入 = 部门内部分配给他的金额

- 员工每月正常发放基本工资和绩效工资。

- 项目提成在项目回款后（可能分多次回款，则按回款比例发放）的3个月内发放，发放金额为根据项目分配方案计算出的个人应得提成。

- 在项目提成发放的当月，该员工会收到两笔钱：工资和项目提成。

五、部门储备金账户：

部门储备金账户的来源：

1. 项目提成中部门留存的部分（如上面的20%）

2. 其他可能来源（如公司额外奖励等）

部门储备金账户的用途：

1. 部门年终奖：在年度考核达标后，部门可以用储备金发放年终奖。

2. 部门建设：购买设备、团队活动等。

注意：部门年终奖的发放前提是部门年度考核达标（按达标系数发放）。

六、绩效工资的发放条件：

销售部门:
只有当月绩效考核指标达标，才能发放绩效工资。否则，只发基本工资。
其他部门：
根据当月绩效考核指标考核情况按考评比例发放绩效工资。

大额提成/奖金分期发放：

对于单笔超过10万元的个人收入（包括项目提成和年终奖），采用分期发放，比例：50%（首期）+30%（3个月后）+20%（6个月后）。

八、部门分红(部门年终奖)

- 部门分红来源于储备金账户

- 前提：部门年度业绩达标。

- 分配：公司根据各部门的贡献（如主导项目的部门、协同部门）制定分配方案，然后部门内部再根据员工的贡献进行分配。

- 发放时间：年度，在公司审核后发放。

九、其他奖励

- 如考取证书、完成特定研发、攻坚奖励等，按公司相关制度执行。

十、薪酬计算流程

1. 每月工资计算：

- 基本工资（固定）+ 绩效工资（根据月度绩效考核结果计算）

- 绩效工资计算依据：个人月度绩效考核结果（绩效系数）

2. 项目提成计算（在项目回款后）：

- 根据项目结项时的毛利润计算项目提成总额（毛利润×50%）。

- 根据项目人员毛利分配表（在项目立项时设定，结项时调整确认）计算每个人的项目提成。

- 项目提成在回款后3个月内发放。

九、薪酬计算逻辑

1. 每月工资计算逻辑（按月执行）：

- 遍历所有员工，获取该员工的基本工资（固定）。

- 根据该员工的当月绩效考核结果（个人绩效考核表）计算绩效工资：绩效基数 × 绩效系数。

- 汇总：当月工资 = 基本工资 + 绩效工资。

2. 项目提成计算逻辑（在项目回款后触发）：

- 根据项目回款记录，计算该项目的毛利润（实际回款金额 - 项目成本）。

- 项目提成总额 = 毛利润 × 50%。

- 根据项目人员毛利分配表（调整后最终版）计算每个参与员工的提成金额。

- 记录到项目提成发放表，并安排发放（可分批发放，但通常一次性发放）。

3. 部门分红计算逻辑（年度触发）：

- 分红来源于部门储备金账户级年终利润公司划拨。

- 检查各部门年度业绩目标完成情况（根据部门绩效考核结果表），只对达标的部门分配。

- 部门负责人提交部门内部分配方案（员工分配比例），审批通过后，按方案计算每个员工的分红金额。

- 记录到部门分红发放表，安排发放。

4. 全员销售奖励计算逻辑（在商机提供或销售促成的当月或下月）：

- 商机提供：在商机被确认有效时，发放固定金额，记录到全员销售奖励表。

- 促成销售：在合同签订并生效后，按合同金额的比例计算奖励，记录到全员销售奖励表。

5. 其他奖励：根据相关制度，触发时记录到其他奖励表。

十、注意事项

- 项目提成和部门分红需要扣税，具体扣税规则按国家规定。

- 所有奖励和提成的发放都需要经过审批流程。

以上为薪酬计算方案的初步设计，具体实现时还需与业务方确认细节。
