## 🐛 已知问题和解决方案

### 1. 部门编号重复问题
**现象**: 编辑时提示"部门编号已存在"
**可能原因**:
1. 后端验证逻辑没有排除当前编辑的部门
2. 数据传递格式问题（已修复：确保ID是数字类型）

**临时解决方案**:
- 如果编辑时确实需要保持原部门编号不变，用户可以忽略此错误
- 或者暂时修改部门编号为新的唯一值

**彻底解决方案**:
- 联系后端开发人员，确认编辑接口的验证逻辑
- 可能需要在后端验证时排除当前编辑部门的ID

### 2. 员工API 404问题
**现象**: 获取员工列表时返回404错误
**解决**: 暂时使用模拟数据，保证功能正常使用
**后续**: 等员工管理模块完善后，启用真实API
