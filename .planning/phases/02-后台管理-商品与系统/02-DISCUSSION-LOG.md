## 商品发布配置

| Option | Description | Selected |
|--------|-------------|----------|
| 先上传后选择（推荐） | 图片先上传到OSS，保存商品时直接引用URL。流程清晰但多一步操作 | ✓ |
| 富文本编辑器直传 | 在富文本编辑器中直接粘贴上传 | |
| Base64内嵌 | 图片转Base64直接存储，简单但存储成本高 | |

**User's choice:** 先上传后选择（推荐）

---

## SKU规格配置

| Option | Description | Selected |
|--------|-------------|----------|
| 预定义规格+规格值池（推荐） | 后台预定义规格名称，每个规格有可选值列表。发布商品时勾选并设置价格/库存 | ✓ |
| 完全自由规格 | 发布商品时随时新增规格名称和规格值 | |
| 固定规格模板 | 每个商品类别有固定SKU模板 | |

**User's choice:** 预定义规格+规格值池（推荐）

---

## 虚拟商品库存

| Option | Description | Selected |
|--------|-------------|----------|
| 无限库存（-1）（推荐） | 虚拟商品默认无限库存，支付时不做库存校验 | |
| 固定库存+人工补货 | 虚拟商品也需设置具体库存数量，卖完需管理员手动增加 | ✓ |
| 按需生成 | 不预占库存，下单支付成功后实时生成交付物 | |

**User's choice:** 固定库存+人工补货（选择了比推荐更严格的库存管理方式）

---

## 轮播图链接

| Option | Description | Selected |
|--------|-------------|----------|
| 内部商品（推荐） | 链接到具体商品详情页 | |
| 外部URL | 可配置任意外部链接，支持营销活动页 | |
| 混合模式 | 支持内部商品和外部URL两种，通过字段区分 | ✓ |

**User's choice:** 混合模式

---

## 统计卡片数据策略

| Option | Description | Selected |
|--------|-------------|----------|
| 每日定时统计（推荐） | 每日凌晨/每小时跑批任务统计，数据库压力小 | |
| 准实时统计（缓存）（推荐） | Redis缓存当日数据，每5分钟刷新，兼顾性能和实时性 | ✓ |
| 实时查询（不推荐） | 每次访问实时聚合计算，大数据量时影响性能 | |

**User's choice:** 准实时统计（缓存）（选择了性能和实时性的平衡）

---

## 统计卡片指标

| Option | Description | Selected |
|--------|-------------|----------|

## 资源有效期

| Option | Description | Selected |
|--------|-------------|----------|
| 固定过期时间（推荐） | 管理员配置固定过期天数，从订单完成时间起算 | ✓ |

## 批量上下架交互

| Option | Description | Selected |
|--------|-------------|----------|
| 50件/批（推荐） | 每次最多勾选50件，超过提示分批操作 | ✓ |
| 100件/批 | 支持更大批量，需前端分页勾选避免卡顿 | |
| 不限数量 | 后端按条件批量更新，灵活但风险较高 | |

**User's choice:** 50件/批（推荐）

---

## 分类树操作

| Option | Description | Selected |
|--------|-------------|----------|
| 增删改+排序（推荐） | 支持新增/编辑/删除/拖拽或序号调整排序/设置分类图标 | ✓ |

## 微信支付配置安全

| Option | Description | Selected |
|--------|-------------|----------|
| 加密存储（推荐） | AES加密后存储，界面脱敏展示（api-key显示后4位） | ✓ |

## 商品克隆/复制

| Option | Description | Selected |
|--------|-------------|----------|
| 支持克隆（推荐） | 提供克隆按钮，复制商品信息+SKU规格，减少重复录入 | ✓ |
