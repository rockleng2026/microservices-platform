<action>
定位 Result.succeed() 方法。当前问题是 `Result.succeed()` 当返回类型为 `Result<Void>` 时，Java 泛型无法从 `null` 推断 `Void` 类型。

将现有的 `Result.succeed()` 方法修改为显式声明返回 `Result<Void>`：

```java
public static Result<Void> succeed() {
    Result<Void> result = new Result<>(null, CodeEnum.SUCCESS.getCode(), "");
    return result;
}
```

同时保留原有的 `public static <T> Result<T> succeed(T data)` 方法以维持向后兼容。
</action>
