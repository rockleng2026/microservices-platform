
优化下计算设计思路：
1. 表达式解析：将表达式字符串解析成可以计算的形式。考虑到括号和函数，我们可以使用栈或者递归下降解析，但为了简单，我们可以先考虑使用现有的表达式解析库，或者自己实现一个简单的递归解析。
2. 数据类型处理：在计算前，需要将各种数据类型转换为统一的数值类型（比如小数）。对于BOOLEAN，我们可以转换为1（true）和0（false）；对于STRING，如果内容是可解析为数字的字符串，则解析为数字，否则报错；PERCENTAGE需要除以100。
3. 函数支持：支持AVG（平均值）、SUM（求和）、MAX（最大值）、MIN（最小值）。这些函数可以接受多个参数，参数可以是表达式、常量或变量。


由于我们是在一个配置环境中，变量可能来自配置表，因此我们需要一个上下文（context）来提供变量的值。
步骤：
1. 词法分析：将表达式分解成令牌（token），包括数字、运算符、括号、函数名、变量名等。
2. 语法分析：根据令牌构建抽象语法树（AST）。
3. 计算：遍历AST，递归计算每个节点的值。
   考虑到复杂度，我们可以分步骤实现，先实现不带函数的，再逐步加入函数。
   功能说明文档：
1. 支持的数据类型：
  - NUMBER: 整数或浮点数，直接参与计算。
  - DECIMAL: 高精度的十进制数，用于避免浮点误差，在计算中我们使用decimal.Decimal处理（如果使用Python）。
  - PERCENTAGE: 百分比，在计算前需要除以100转换为小数。
  - CURRENCY: 货币，和DECIMAL类似，直接作为数值处理。
  - BOOLEAN: 布尔值，true转换为1，false转换为0。
  - STRING: 字符串，如果字符串内容可以解析为数字（包括整数、小数、科学计数法等），则解析为数字，否则抛出异常。
2. 运算符：
  - 加法: +
  - 减法: -
  - 乘法: *
  - 除法: / （注意，除法在整数除时需要注意，但因为我们有DECIMAL类型，建议统一使用浮点数或Decimal进行除法）
3. 括号: () 用于改变运算优先级。
4. 函数：
  - AVG(expr1, expr2, ...): 计算多个表达式的平均值。
  - SUM(expr1, expr2, ...): 计算多个表达式的和。
  - MAX(expr1, expr2, ...): 返回多个表达式中的最大值。
  - MIN(expr1, expr2, ...): 返回多个表达式中的最小值。
5. 计算过程：
  - 首先，获取表达式中所有变量的值，并根据其数据类型转换为统一的数值（如果是PERCENTAGE则除以100）。
  - 然后，按照运算符优先级和括号顺序计算表达式。
  - 函数调用时，先计算每个参数表达式的值，然后执行函数。
6. 错误处理：
  - 除数为0：抛出异常。
  - 变量不存在：抛出异常。
  - 类型不匹配：例如字符串无法转换为数字，抛出异常。
    设计类：
1. 计算引擎类：CalculatorEngine
   主要方法：
  - evaluate(expression: str, context: dict) -> Union[int, float, Decimal]: 计算表达式的值，context提供变量的值。
2. 辅助类：
  - 词法分析器：将表达式字符串拆分成token。
  - 语法分析器：构建AST。
  - 解释器：遍历AST计算值。

功能说明文档：
1. 表达式语法：
   表达式由数字、变量、运算符、函数调用和括号组成。
   运算符包括：+ (加), - (减), * (乘), / (除)
   优先级：乘除 > 加减，括号可以改变优先级。
   函数调用：函数名(参数1, 参数2, ...)，参数可以是表达式。
2. 支持的函数：
   AVG: 求平均值，例如：AVG(1,2,3) 结果为2。
   SUM: 求和，例如：SUM(1,2,3) 结果为6。
   MAX: 最大值，例如：MAX(1,3,2) 结果为3。
   MIN: 最小值，例如：MIN(1,3,2) 结果为1。
3. 变量：
   变量由字母、数字、下划线组成，不能以数字开头。
   变量必须在上下文中定义，上下文是一个字典，键是变量名，值是字典{'value': 变量的原始值, 'type': 数据类型}。
   数据类型为：'NUMBER','DECIMAL','PERCENTAGE','CURRENCY','BOOLEAN','STRING'
4. 数据类型转换规则：
   在计算前，变量值会根据其数据类型转换为数值（浮点数）：
   - NUMBER, DECIMAL, CURRENCY: 直接转换为浮点数。
   - PERCENTAGE: 转换为浮点数后再除以100。
   - BOOLEAN: true转为1.0，false转为0.0。
   - STRING: 尝试转换为浮点数，失败则报错。
5. 计算精度：
   使用浮点数计算，可能存在精度问题。对于需要高精度的场景（如货币），建议使用Decimal，但我们在设计中使用的是float，可以根据需要改为Decimal。
6. 示例：
   表达式："(1 + 2) * 3" 结果为9。
   表达式："SUM(1,2,3)" 结果为6。
   表达式："10% + 20%"  如果10%对应的变量是PERCENTAGE类型，则值为0.1+0.2=0.3。
