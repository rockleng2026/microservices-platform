**Page layout:**

1. **Countdown timer** (top, prominent):
   - "订单保留时间" label + "29:59" countdown display
   - Uses setInterval updating every second
   - On reaching 0: shows "订单已过期" and disables pay button
   - Per D-09: 30-minute countdown, order auto-closes server-side

2. **Order info card** (white card, 8px radius):
   - "订单号: {orderId}" with copy button (uni.setClipboardData)
   - "订单金额: ¥{amount}" (accent color, bold)
   - Created time

3. **WeChat Pay button** (bottom, full-width):
   - Large accent button: "微信支付 ¥{amount}"
   - Per D-11: on tap → call POST /api/mall/pay/create with { orderId } → receive { prepay_id, timestamp, nonceStr, signType, paySign } → call wx.requestPayment({ ... })
   - If API fails: show error toast
   - If wx.requestPayment succeeds: redirectTo /pages/payment/result?orderId={orderId}&status=success
   - If wx.requestPayment fails: redirectTo /pages/payment/result?orderId={orderId}&status=fail

4. **Retry payment** (per D-10, MINI-10-05):
   - If order is already in pending payment state, "重新支付" button
   - Same flow as above

**Payment flow per D-11:**
```
1. User taps "微信支付"
2. Show loading: "正在唤起支付..."
3. POST /api/mall/pay/create { orderId }
   Response: { prepay_id, timestamp, nonceStr, signType, paySign, packageValue }
4. Call wx.requestPayment({
     timeStamp: timestamp,
     nonceStr: nonceStr,
     package: `prepay_id=${prepay_id}`,
     signType: signType,
     paySign: paySign
   })
5. On success → redirectTo result page with success
6. On fail → redirectTo result page with fail
```

**Package value note:** WeChat JSAPI requires `package` field with value `prepay_id={prepay_id}` (note the underscore and lowercase). Ensure the backend returns `packageValue` field or format `prepay_id=${prepay_id}` in frontend.

**Styling:**
- Countdown: large font (24px), centered, red if < 5 minutes
- Order card: white bg, 8px radius, shadow
- Pay button: full width, 48px height, accent #ff5500, border-radius 24px
