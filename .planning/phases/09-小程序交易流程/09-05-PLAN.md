Build pages/refund/apply.vue for refund application:

**API endpoints to add in config/api.ts:**
```
REFUND_APPLY = '/api/mall/refund/apply'

```

**Page layout:**

1. **Order info card** (top, white card):
   - "订单信息" header
   - Order number + created time
   - Shows refund item(s) summary: image thumbnails + item names + quantities
   - Refund amount display: "退款金额: ¥{amount}" (accent color, bold)

2. **Refund reason section**:
   - "退款原因" header (required label)
   - **Preset reason list** (radio group, per D-17):
     - Radio buttons vertically stacked
     - Options: "不想要了" | "商品损坏" | "发错货" | "与描述不符" | "其他"
     - Selected: accent border + filled radio
   - **Custom reason text input** (shows when "其他" is selected):
     - Textarea: "请输入退款原因" placeholder
     - Max 200 characters
     - Character count display

3. **Image upload section** (per D-18):
   - "上传凭证" header (optional)
   - Upload grid: up to 3 images
   - Each image: 80x80 thumbnail with X delete button on top-right corner
   - "+" add button: taps to open image chooser (uni.chooseImage)
   - Per D-18: maximum 3 images
   - When 3 images already added, hide add button
   - Delete: tap X to remove from list

4. **Submit button** (bottom, fixed or inline):
   - "提交退款申请" button (accent #ff5500, full width, 44px height)
   - Disabled state if no reason selected (or "其他" selected but no text)
   - On submit: POST /api/mall/refund/apply with { orderId, reason, otherReason?, images[] }
   - On success: show toast "退款申请已提交" + navigateBack()
   - On error: show toast "提交失败，请重试"

5. **Refund status display** (if already applied):
   - If refund already exists for this order, show status section instead of form
   - "退款进度" section:
     - Status badge: "申请中" (orange) / "已通过" (green) / "已拒绝" (red)
     - Refund amount shown
     - Application time
     - Rejection reason (if rejected)
   - "取消退款申请" button (destructive outline #ff4d4f, only if status is 申请中)
     - Per MINI-08-06: cancel before admin processes
     - Tap → confirm dialog "确定要取消退款申请吗？"
     - Confirm → DELETE /api/mall/refund/{id}
     - Success → show toast + navigateBack()

**Image chooser behavior:**
- Use uni.chooseImage({ count: 3 - currentImages.length, sourceType: ['album', 'camera'] })
- After selection: upload each to backend image upload endpoint
- Show loading during upload
- Add returned URLs to images array

**Backend image upload (assumed endpoint):**
- POST /api/mall/upload to upload image file
- Returns: { url: 'https://...' }

**API calls:**
- GET /api/mall/refund?orderId={orderId} — check if refund already exists
- POST /api/mall/refund/apply — create refund application
  - Body: { orderId, reason, otherReason?, images?: string[] }
- DELETE /api/mall/refund/{id}/cancel — cancel refund application (MINI-08-06)

**Styling per 08-UI-SPEC:**
- Card: white bg, 8px radius
- Section spacing: 16px
- Reason radio: 44px touch height, left radio icon
- Image grid: 3 columns, 8px gap
- Add button: dashed border, gray icon
- Submit button: accent #ff5500, border-radius 22px
