# 在线销售平台（小程序+管理后台）需求与设计方案

> 文档版本: 1.0  
> 创建日期: 2026-05-08  
> 基于平台: central-platform v6.0.0  
> 业务命名: **hardware-mall** (硬件商城)

---

## 1. 项目概述

### 1.1 项目背景

在 central-platform 微服务架构基础上，构建一个专注于服务器、CPU、内存、NAS 等企业级硬件商品的在线销售平台。  
前端载体为**微信小程序**，面向下游企业/个人客户提供商品浏览、下单、支付、物流追踪等电商体验。  
后端提供一套**管理后台 Web**，供运营人员完成商品上架、订单处理、库存管理、客户管理等工作。

### 1.2 设计目标

- 复用现有微服务体系：Nacos 注册/配置、OAuth2 认证、网关路由、多租户等基础设施
- 新增一个独立的业务服务 `hardware-mall-center`，承担商城所有业务逻辑
- 保持数据隔离，兼容多租户模式（预留 `tenant_id`）
- 小程序端通过 HTTPS REST API 调用后端服务，经过网关认证与限流
- 管理后台为独立前端项目，调用同一套 REST API（携带管理权限）

### 1.3 核心特性

- **SKU 商品模型**：支持多规格（如 CPU 不同型号、内存容量等），独立库存与价格
- **库存安全扣减**：基于 Redis 原子操作 + 数据库最终一致
- **微信支付集成**：JSAPI 支付 + 支付回调通知
- **物流追踪**：接入第三方物流接口或手工录入运单
- **评价体系**：订单完成后可评价商品
- **多租户底座**：表结构支持 `tenant_id`，可扩展为 SaaS 多店模式

## 2. 需求分析

### 2.1 用户角色

| 角色       | 说明                   | 权限范围                                     |
| ---------- | ---------------------- | -------------------------------------------- |
| 小程序用户 | 通过微信登录的买家     | 浏览商品、加购、下单、支付、查看订单、评价   |
| 管理员     | 后台运营人员           | 商品管理、订单处理、发货、库存调整、查看数据 |
| 超级管理员 | 多租户环境下的最高权限 | 包含管理员权限 + 租户管理、系统配置          |

### 2.2 功能模块

#### 2.2.1 小程序端（用户侧）

**商品模块**

- 首页：轮播广告、分类入口、推荐商品
- 商品搜索：按名称、分类、参数模糊搜索
- 商品列表：分类筛选、排序（价格、销量、新品）
- 商品详情：多规格 SKU 选择、库存显示、图文详情
- 购物车：加入购物车、修改数量、规格切换、合计金额

**订单模块**

- 生成订单：从购物车创建，填写收货地址，支持买家留言
- 订单支付：唤起微信支付，支付成功/失败状态展示
- 订单列表：按状态（待付款、待发货、已发货、已完成、已取消）筛选
- 订单详情：包含物流信息（已发货时展示运单号、物流轨迹）
- 取消订单：待付款状态可取消，已付款需走退款流程（可后台处理）
- 确认收货：用户主动确认或超时自动确认

**用户模块**

- 微信授权登录（OAuth2 ↔ 微信 OpenID 绑定）
- 收货地址管理（增删改查，默认地址）
- 个人信息（头像、昵称）
- 我的评价

**其他**

- 支付成功回调处理
- 公告/帮助页面

#### 2.2.2 管理后台（运营侧）

**商品管理**

- 商品分类管理（树形结构）
- 商品列表（支持条件搜索、批量上下架）
- 发布/编辑商品：基本信息、商品图集、SKU 规格（如 CPU 型号、内存容量、硬盘）、销售价格、库存数量
- 商品详细描述（支持富文本）

**订单管理**

- 订单列表：多条件筛选（订单号、状态、时间、商品名称）
- 订单详情：查看商品明细、买家信息、物流信息
- 发货处理：填写/导入运单号、选择物流公司（可在设置中维护）
- 退款处理：审核退款请求（需扩展退款逻辑）

**库存管理**

- 商品 SKU 库存查看与修正（可增减库存，记录操作日志）
- 库存预警：低于阈值时标记提醒

**客户管理**

- 用户列表：查看注册用户（关联微信信息）
- 用户订单、消费统计

**营销工具（可选一期）**

- 优惠券管理（满减券、折扣券）
- 促销活动（限时折扣）

**系统设置**

- 广告位管理（首页轮播图）
- 物流公司配置
- 支付配置（微信支付参数）
- 租户配置（若多租户，可切换当前租户上下文）

### 2.3 核心业务流程

#### 购买流程

```
用户浏览商品 → 选规格加入购物车 → 进入购物车确认 → 创建订单（锁定库存）
→ 唤起微信支付 → 支付成功（扣减库存，更新订单状态） → 商家发货 → 用户收货 → 评价
```

**库存扣减时序**：

- 下单时预占库存（Redis 锁或预扣，可设置订单超时取消回滚库存）
- 支付成功后真实扣减
- 若支付超时未付，自动取消订单并释放库存

#### 退款流程（二期可完善）

```
用户/管理员发起退款 → 管理员审核 → 通过后原路退款（微信支付退款接口） → 回增库存
```

### 3.4 与现有服务的协作

- **user-center**：用户基础信息、管理员身份识别（Feign 或直接共享 DB）
- **file-center**：商品图片、轮播图上传（通过 OSS starter 统一调用）
- **zlt-uaa**：认证令牌生成与校验，小程序通过 code 换取 Token（微信登录集成到 UAA 回调或新增 endpoint）
- **zlt-gateway**：路由 `hardware-mall-center` 的所有接口

**微信登录适配方案**：  
可在 `zlt-uaa` 中增加微信登录接口，接收小程序传回的 `code`，换取 `openid` 和 `session_key`，然后生成平台 JWT Token 返回。`hardware-mall-center` 内部不处理登录，仅从 Token 中解析用户 ID。

## 5. API 设计

> 所有 API 前缀统一为 `/api/mall`，由网关转发至 `hardware-mall-center`。  
> 管理后台接口加 `/admin` 前缀，通过权限注解控制，例如 `/api/mall/admin/goods/**`。

### 5.1 小程序端 REST API

#### 商品

| 方法 | 路径              | 说明                                     |
| ---- | ----------------- | ---------------------------------------- |
| GET  | /goods/categories | 获取分类树                               |
| GET  | /goods/list       | 商品列表（支持分类、关键词、排序、分页） |
| GET  | /goods/{id}       | 商品详情（含 SKU）                       |
| GET  | /goods/hot        | 热门/推荐商品                            |

#### 购物车

| 方法   | 路径        | 说明                          |
| ------ | ----------- | ----------------------------- |
| POST   | /cart       | 加入购物车（skuId, quantity） |
| GET    | /cart/list  | 我的购物车列表                |
| PUT    | /cart/{id}  | 修改数量或选中状态            |
| DELETE | /cart/{id}  | 删除一项                      |
| DELETE | /cart/clear | 清空已选中项                  |

#### 收货地址

| 方法   | 路径                  | 说明         |
| ------ | --------------------- | ------------ |
| GET    | /address/list         | 我的地址列表 |

## 6. 前端设计要点

### 6.1 微信小程序

**技术选型**：

- 原生框架开发或 `uni-app` / `Taro`（便于多端）
- 网络请求封装：统一 Token 注入、异常拦截
- 支付模块：`wx.requestPayment` 调用

**页面结构**：

```
首页 (index)              → 搜索、轮播、分类、推荐
分类页 (category)         → 商品分类树，点击进入商品列表
商品列表 (goods-list)     → 筛选排序，下拉加载更多
商品详情 (goods-detail)   → SKU 选择弹层，加购、直接购买
购物车 (cart)             → 全选、改数量、结算
订单确认 (order-confirm)  → 选择地址、备注、优惠券占位
我的订单 (order-list)     → 按状态 Tab 切换
订单详情 (order-detail)   → 物流进度，评价入口
收货地址 (address)        → 新增/编辑地址
我的 (center)             → 用户信息、入口菜单
```

**支付流程封装**：

1. 用户点击支付 → 调用 `/api/mall/order/{id}/pay` 获取 `timeStamp`, `nonceStr`, `package`, `signType`, `paySign`
2. 小程序调用 `wx.requestPayment`，成功后跳转订单详情

### 6.2 管理后台 Web

**技术选型**：

- 基于现有 `zlt-web` 或独立 Vue3 + Element Plus / Ant Design Vue 项目
- 状态管理：Pinia
- 请求库：Axios，携带 Admin Token（从 UAA 获取）

**功能页面**：

```
登录页                   → 管理员账号密码登录
仪表盘                  → 今日订单数、销售额、待发货等统计卡片
商品管理                → 列表 / 新建/编辑商品（SKU 动态表格）
订单管理                → 列表 + 详情 + 发货弹窗
库存管理                → 商品 SKU 库存修改
客户管理                → 用户列表、订单记录
营销中心                → 优惠券、活动（扩展）
系统设置                → 轮播图、快递、支付参数
```

**权限控制**：

- 网关层校验 Token 中的 `authorities` 包含 `ROLE_ADMIN`
- 前端路由守卫：无 Token 跳转登录，调用认证接口获取 Token

### 7.1 开发步骤

1. **数据库搭建**：执行上述 SQL 创建库表

## 8. 扩展性考虑

- **多租户**：已有 `tenant_id` 字段，若后期开放给多个供应商，只需在管理员端增加租户切换，业务代码零改动（租户拦截器自动处理）
- **营销模块**：优惠券/活动可单独建表，订单计算时聚合优惠金额
- **售后/退款**：增加 `mall_refund` 表，关联订单，对接微信退款 API
- **搜索优化**：商品数据索引至 Elasticsearch（通过 `zlt-elasticsearch-spring-boot-starter`），提升搜索体验
- **库存安全**：可改用 Redis Lua 脚本扣减库存，数据库异步同步，进一步提升并发性能
