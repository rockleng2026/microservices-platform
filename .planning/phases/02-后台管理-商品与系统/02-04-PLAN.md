Create ResourceController (NOT in admin/ subfolder, this is user-facing):

Endpoints:
- GET /api/mall/resource/download/{deliveryId} — downloadResource(@PathVariable, @RequestParam token, @RequestParam expire)

Logic:
1. Validate deliveryId exists in mall_resource_delivery
2. Validate token matches delivery.token
3. Validate expire time not passed (expire > now)
4. Increment download_count
5. Redirect to resource_url or return download URL
6. If validation fails, return 403/404 error

Use @Tag(name = "资源下载", description = "虚拟商品资源下载接口"). This URL format (D-07) is: `/api/mall/resource/download/{deliveryId}?token={token}&expire={timestamp}`

Note: mall_resource_delivery records are created by Phase 3 (order payment callback). This endpoint just validates and serves existing records.
