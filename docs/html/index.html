项目说明

本原型基于 Portal 3.0 微服务重构项目需求文档 设计，采用现代化UI/UX设计理念，

完整展示了OA办公自动化、CRM客户关系管理、进销存库存管理三大核心业务模块的界面设计。

所有页面均采用响应式设计，兼容桌面端、平板端和移动端设备。
