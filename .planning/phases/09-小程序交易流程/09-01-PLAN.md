  <action>
Extend CartStore in mall-mini-program/src/stores/cart.ts to add the following methods needed by the cart page:

1. Add `selectedItems: Set<number>` private field tracking selected skuIds
2. Add `getSelectedItems(): CartItem[]` — returns items whose skuId is in selectedItems (if empty, return all as selected by default)
3. Add `getSelectedTotal(): number` — sum of price * quantity for selected items
4. Add `toggleSelect(skuId: number): void` — add/remove skuId from selectedItems
5. Add `selectAll(selected: boolean): void` — set all current items selected or deselected
6. Add `isAllSelected(): boolean` — returns true if selectedItems contains all current items
7. Add `getSelectedSkuIds(): number[]` — returns array of selected skuIds for checkout navigation
8. Add `syncToServer(): Promise<void>` — POST all local items to /api/mall/cart/sync with userId header, called on login

Extend mall-mini-program/src/services/cart.ts to add:
- `getCartList(userId: string): Promise<CartItem[]>` — GET /api/mall/cart with userId header (returns full cart with goods details)
- `syncCartToServer(items: CartItem[], userId: string): Promise<void>` — POST /api/mall/cart/sync to merge local cart to server

The mixed mode logic:
- On app start, check if user is logged in (userId in storage)
- If logged in: load from server via getCartList, fall back to local if API fails
- If not logged in: use local storage (existing behavior)
- When user logs in: call syncToServer to push local items to server
- Per D-01, D-02: allow mixed physical + virtual items without restriction
