## 🧪 后端API验证

### 1. 分管岗位查询验证
```sql
-- 验证技术总监（岗位ID=2）的分管岗位
SELECT wp.id, wp.name, wp.short_name 
FROM workposition wp
INNER JOIN workposition_manage_dept wmd ON wp.id = wmd.charge_workposition_id
WHERE wmd.workposition_id = 2 AND wmd.tenant_id = 'default'
AND wp.status = 1 AND wp.delflag = 0;
```
**预期结果**: 应该返回前端开发经理、后端开发经理等岗位

### 2. API接口验证
```bash
# 获取用户信息（包含岗位列表）
curl -X GET "http://localhost:9900/api-portal/users/current" \
  -H "Authorization: Bearer YOUR_TOKEN"

# 获取用户岗位列表
curl -X GET "http://localhost:9900/api-portal/users/positions" \
  -H "Authorization: Bearer YOUR_TOKEN"

# 切换岗位
curl -X POST "http://localhost:9900/api-portal/users/switch-position?positionId=6" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
