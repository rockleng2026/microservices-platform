# 绩效考核模块菜单设计

## thinking
我们设计的功能菜单需要覆盖之前提到的所有核心功能点，并按照逻辑层次组织。菜单分为前端用户界面（不同角色可见不同菜单）和后端管理界面（HR或管理员使用）。这里我们主要设计前端用户界面的功能菜单，因为后端管理功能已部分包含在微服务接口中。
根据角色划分：
1. 员工
2. 直属领导（部门经理等）
3. HR或绩效管理员
   我们设计三级菜单结构：主菜单 -> 子菜单 -> 功能点
   注意：菜单的显示会根据角色动态变化。
   以下是详细的功能菜单设计：
### 一、员工端菜单
员工只能看到与自己相关的绩效内容。
1. **我的绩效**
    - 当前考核任务：展示当前需要自评或待办的任务，进入后是自评界面（包含指标填写、证明上传、实时得分计算）
    - 历史绩效：按时间倒序列出自己参与过的所有考核计划，点击可查看历史考核的详细报告（总分、评级、各指标得分等）
    - 绩效申诉：如果对已完成的绩效评定有异议，可以在此提交申诉（关联调整请求）
2. **指标库查询**（只读）
    - 查看全局KPI池中与自己岗位相关的指标，了解指标定义和计算方式。
### 二、领导端菜单（部门经理等）
领导可以看到自己团队所有成员的绩效信息。
1. **团队绩效**
    - 考核任务分配：查看当前考核周期内需要为下属分配的指标（如果系统支持领导为下属定制指标）
    - 待我评分：列出所有需要自己评分的下属考核任务（可批量进入评分界面）
    - 团队绩效进度：以仪表盘形式展示团队整体考核完成情况（自评完成率、评分完成率等）
    - 团队绩效结果：查看下属的历史绩效报告（汇总视图，支持按时间、员工过滤）
2. **绩效调整**
    - 调整申请审批：下属提交的绩效调整申请，领导在此审批（同意/驳回）
    - 发起调整：主动为下属发起绩效调整（如发现指标数据有误）
3. **绩效分析**
    - 团队对比分析：对比不同下属的绩效得分，生成雷达图或柱状图
    - 趋势分析：查看团队绩效的历史变化趋势
### 三、HR/绩效管理员端菜单
拥有最全面的权限，可进行全局配置和监控。
1. **绩效计划管理**
    - 考核计划创建：新建考核计划，设置周期、选择参与的部门/员工
    - 计划列表：查看所有考核计划（状态：草稿、进行中、已结束）
    - 计划详情：进入某个计划，监控该计划的执行情况（各部门进度、完成率）
2. **KPI库管理**
    - 指标分类管理：对KPI分类进行增删改查
    - 指标管理：对全局KPI池进行维护（添加、编辑、禁用指标）
    - 指标下发：为部门或员工分配指标（如果未在计划中完成，这里可补）
3. **绩效评定**
    - 评定进度监控：查看全公司各部门的绩效评定进度（自评、领导评分、HR汇总）
    - 异常处理：处理有争议的评分（仲裁）
    - 汇总报告：生成全公司或部门的绩效汇总报告（导出Excel或PDF）
4. **绩效调整**
    - 调整申请审批：审批领导提交的调整申请（最终审批）
    - 调整记录查询：按条件查询历史调整记录
5. **绩效档案**
    - 员工绩效档案：查询任意员工的绩效历史记录
    - 部门绩效档案：按部门查看绩效汇总历史
    - 绩效数据导出：导出全公司绩效数据用于分析
6. **系统设置**
    - 角色权限配置：设置不同角色对菜单和数据的访问权限(这个沿用现有系统岗位的权限体系)
    - 公式引擎配置：维护公式中可用的函数和变量
    - 数据源配置：配置与外部系统（如CRM、考勤系统）的数据对接
    - 通知设置：配置各环节的提醒通知模板
### 四、超级管理员菜单（可选）
如果是独立部署，可能还需要系统管理菜单（用户管理、日志审计等），但通常属于基础权限管理模块，这里不展开。
注意：实际菜单名称可能根据产品定位调整，比如“绩效评定”也可称为“绩效考评”。
以上菜单设计覆盖了之前需求中的所有功能点，并且按照角色隔离了操作权限。在实现时，可以通过角色权限控制系统动态渲染菜单。

## 绩效管理模块功能菜单
1. 全局指标库管理（HR管理员专用）
- 指标分类管理
  - 添加部门分类（销售/技术/行政/公共）
  - 设置分类层级关系
  - 分类权重分配
- KPI池维护
   - 新建标准指标（名称/编码/公式）
   - 指标批量导入/导出
   - 指标版本对比（历史记录）
- 数据源配置
  - 对接业务系统（CRM/考勤/日志）
  - 设置自动采集规则
  - 人工录入字段配置
2. 考核周期管理
- 考核计划创建
  - 设置周期类型（月度/季度/年度）
  - 时间轴配置（自评/部门评/终审节点）
  - 智能拆解设置（自动拆分年度目标）
- 考核任务下发
  - 部门统一下发（批量绑定公共指标）
  - 个人定制指标（追加专属KPI）
  - 员工确认通知（消息中心联动）
- 计划监控看板
  - 部门完成率热力图
  - 逾期任务预警列表
  - 进度实时追踪（甘特图）

3. 绩效评定中心
- 员工自评工作台
  - 待办任务清单
  - 指标卡片式填写（含实时得分计算）
  - 证明附件上传（图片/文档）
  - 历史成绩对比视图
- 领导评分工作台
  - 团队矩阵视图（横向对比）
  - 批量评分模式（Excel式操作）
  - 锚定案例参考库（评分标准）
  - 异常数据提示（偏离均值预警）
- HR终审工作台
  - 争议仲裁处理
  - 权重校准工具
  - 强制分布配置（A/B/C/D比例）
4. 绩效调整管理
- 变更申请
  - 指标权重调整
  - 计算公式修正
  - 数据源变更请求
- 影响分析
  - 变更波及范围预测
  - 前后效果模拟对比
- 审批工作流
  - 多级审批链配置
  - 电子签名确认
  - 变更历史追溯

5. 绩效档案中心
- 个人档案
  - 历史成绩趋势图
  - 能力雷达图（指标维度）
  - 报告下载（PDF/Excel）
- 团队档案
  - 部门排名榜单
  - 人才九宫格矩阵
  - 离职风险预测
- 公司级分析
  - 绩效分布热力图
  - 高绩效员工特征分析
  - 薪酬绩效关联模型
6. 系统配置（管理员专用）
- 角色权限管理(这个沿用现有系统岗位的权限体系，根据岗位取勾选菜单)
  - 员工：仅查看个人数据
  - 领导：团队数据+评分权
  - HR：全局管理+报表导出
- 公式引擎配置
  - 拖拽式公式构建器
  - 脚本调试控制台
  - 函数库管理（预置20+计算函数）
- 通知模板管理
  - 任务到期提醒
  - 评分冲突通知
  - 报告生成推送
