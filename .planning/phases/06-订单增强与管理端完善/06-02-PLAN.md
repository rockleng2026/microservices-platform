```java
/**
 * 销售趋势统计
 * @param type day|week|month
 * @param startDate 开始日期
 * @param endDate 结束日期
 * @return 销售趋势列表
 */
List<SalesTrendDTO> getSalesTrend(String type, String startDate, String endDate);

/**
 * 库存预警列表
 * @return 低于预警阈值的SKU列表
 */
List<StockWarningDTO> getStockWarningList();

/**
 * 用户分析统计
 * @return 用户分析数据
 */
UserAnalysisDTO getUserAnalysis();
```

在 `AdminStatisticsServiceImpl.java`（需先确认是否存在，如果不存在则创建）中实现上述方法。

**getSalesTrend:**
- 根据 type 确定日期分组方式：day=DATE, week=WEEK, month=MONTH
- SQL查询：`SELECT DATE(create_time) as date, COUNT(*) as orderCount, SUM(payAmount) as salesAmount, COUNT(DISTINCT userId) as userCount FROM mall_order WHERE status IN (2,3,4) AND createTime BETWEEN startDate AND endDate GROUP BY DATE(create_time)`
- 空数据返回空列表，不报错

**getStockWarningList:**
- SQL查询：`SELECT s.id as skuId, s.sku_name as skuName, g.id as goodsId, g.goods_name as goodsName, s.stock as realStock, IFNULL(w.threshold, 10) as warningStock, (SELECT COUNT(*) FROM mall_order_item oi WHERE oi.sku_id = s.id AND DATE(oi.create_time) = CURDATE()) as soldToday FROM mall_goods_sku s JOIN mall_goods g ON s.goods_id = g.id WHERE s.stock <= IFNULL(w.threshold, 10) ORDER BY s.stock ASC`
- 空数据返回空列表，不报错
- 注意：w.threshold 来自库存预警阈值配置表（若无此表则用默认值 10）

**getUserAnalysis:**
- 今日新增：`SELECT COUNT(*) FROM mall_user WHERE DATE(create_time) = CURDATE()`
- 本周新增：`SELECT COUNT(*) FROM mall_user WHERE YEARWEEK(create_time) = YEARWEEK(NOW())`
- 本月新增：`SELECT COUNT(*) FROM mall_user WHERE DATE_FORMAT(create_time, '%Y-%m') = DATE_FORMAT(NOW(), '%Y-%m')`
- 活跃用户：`SELECT COUNT(DISTINCT user_id) FROM mall_order WHERE status IN (2,3,4) AND create_time >= DATE_FORMAT(NOW(), '%Y-%m-01')`
- 平均订单金额：`SELECT AVG(pay_amount) FROM mall_order WHERE status IN (2,3,4) AND create_time >= DATE_FORMAT(NOW(), '%Y-%m-01')`
- 所有查询空数据返回0，不报错
