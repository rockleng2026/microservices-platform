Build pages/address/list.vue for address management:

**API endpoints to add in config/api.ts:**
```
ADDRESS_LIST = '/api/mall/address'
```

**Page can be opened two ways:**
1. As a bottom drawer from checkout (query param drawer=true)
2. As a standalone page from personal center (no param)

**Layout when opened as standalone page:**
- Navigation bar: "收货地址" title
- "新增地址" button in top right (uni icons plus)

**Layout when opened as drawer (drawer=true):**
- No nav bar needed, just the list content
- Bottom sheet style: max-height 60vh, white bg, top border-radius 16px

**Address list:**
- GET /api/mall/address with userId header
- Each address item card (white bg, 8px radius):
  - Left: radio button for default (accent #ff5500 when selected)
  - Center: receiverName + phone (bold) on first line, province+city+district+detail on second line (gray)
  - Right side icons: edit (uni-icon: editor), delete (uni-icon: trash)
  - Default badge: "默认" tag if isDefault === 1

**Interactions:**
- Tap radio → set as default: PUT /api/mall/address/{id}/default
- Tap edit icon → navigateTo /pages/address/edit?id={addressId}
- Tap delete icon → show confirm dialog "确定要删除该地址吗？" → DELETE /api/mall/address/{id}
- Tap add button → navigateTo /pages/address/edit (no id)
- Tap address item (when in drawer mode) → call callback with selected address, close drawer

**When used as drawer (drawer=true):**
- Accept selectedAddress callback prop
- On address tap: emit 'select' event with address object
- Provide close button (X) in top right corner
- Slide-down to close animation

**API calls:**
- GET /api/mall/address — list addresses
- PUT /api/mall/address/{id}/default — set default
- DELETE /api/mall/address/{id} — delete address

**Styling per 08-UI-SPEC:**
- Card: white bg, 8px radius, margin 8px
- Default badge: small tag, accent bg
- Icons: 20px, gray color
- Delete confirm: destructive #ff4d4f

Build pages/address/edit.vue for add/edit address:

**API endpoints:**
- POST /api/mall/address — create new address
- PUT /api/mall/address/{id} — update existing address

**Page layout:**

1. **Navigation bar:**
   - Title: "新增收货地址" or "编辑收货地址" based on whether id param exists
   - Right: "保存" text button (accent color)

2. **Form fields:**
   - **收货人**: input text, placeholder "请输入收货人姓名"
   - **手机号**: input tel, placeholder "请输入手机号", maxlength 11
   - **所在地区**: tap triggers picker mode="region" (uni.picker)
     - Shows selected province-city-district as value
     - Default: tap to open region selector
   - **详细地址**: textarea, placeholder "请输入详细地址", max 100 chars
   - **设为默认地址**: toggle switch or radio, default off

3. **Save button** (alternative to nav bar save):
   - Fixed bottom button: "保存" (accent #ff5500, white text, full width)
   - Validate: receiverName required, phone 11 digits, province/city/district required
   - Show error toast if validation fails

**Region picker:**
- Use uni.picker with mode="region"
- On confirm: update selectedRegion string: "provinceCity district"
- Store separate fields: province, city, district

**Behavior:**
- On load: if id exists, GET /api/mall/address/{id} and pre-fill form
- On save: validate fields, then:
  - If id exists: PUT /api/mall/address/{id} with form data
  - If new: POST /api/mall/address with form data
- On success: navigateBack() or emit 'saved' event
- On API error: show error toast "保存失败，请重试"

**Delete button** (only shown when editing existing address):
- Below form, destructive text button "删除收货地址"
- Tap: confirm dialog → DELETE /api/mall/address/{id} → navigateBack

**Styling per 08-UI-SPEC:**
- Form fields: border-bottom style or card style
- Labels: 14px, text-primary #333
- Inputs: 16px, full width
- Section spacing: 16px vertical
- Save button: full width, 44px height, border-radius 22px, accent bg
