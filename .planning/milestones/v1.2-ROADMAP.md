## Milestone Summary

**Key Decisions:**
- Decision: 使用 Spring Data Redis scripting 替代 Redisson evalReadOnly（Rationale: Redisson API 不存在但效果相同）
- Decision: 商户审批后自动生成 `MERCHANT_{id}` 作为 tenantId（Rationale: 运营层面多租户隔离）

**Issues Resolved:**
- Result.succeed() 泛型问题导致编译失败 → 添加显式 `Result<Void> succeed()` 重载方法
- 退款状态机：待审核→审核通过→退款中→已完成/失败
- 优惠券与促销活动互斥，同一订单只能使用一种

**Issues Deferred:**
- 微信支付联调（需要真实商户参数）
- 积分兑换商品（复杂度高，二期再做）
- 限时秒杀（Redis原子扣减库存，可复用 Lua 脚本）

**Technical Debt Incurred:**
- Phase 5 无独立 VERIFICATION.md（legacy continuation from v1.1）
- OrderServiceImpl.java line 45 TODO（zlt-uaa 集成，pre-existing）
