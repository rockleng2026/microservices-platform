## Key Implementation Details

### Redis Stock Pre-allocation (STOCK-01,02,03)
- Key pattern: `sku:stock:{skuId}` — 当前可用库存
- Key pattern: `order:stock:lock:{orderId}` — 订单预占记录（Redis Hash）
- Unlimited stock (stock=-1) skips Redis operations
- DECRBY返回负数时自动回滚（INCRBY）

### Order Status Flow
- 1=待付款 → createOrder创建时
- 2=已付款 → updateOrderPaid (支付成功后)
- 3=已发货 → shipOrder (管理员发货)
- 4=已完成 → confirmReceipt 或虚拟商品自动完成
- 5=已取消 → cancelOrder

### Virtual Goods Auto-complete (ORDER-09, PAY-04)
- 支付成功后虚拟商品直接进入status=4
- 自动生成MallResourceDelivery交付记录
