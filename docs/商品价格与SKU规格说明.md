# 商品价格与SKU规格说明

## 常见问题

### Q: 新增商品时填了商品价格，又填了多个SKU价格，购买时以哪个价格为准？

**A: 以SKU价格为准（如果有SKU的情况下）**

---

## 价格架构说明

### 1. 商品主价格（price）

位置：商品表单的「商品价格」字段

用途：
- 作为商品的基础价格
- 当商品**没有SKU规格**时，作为最终销售价格
- 也作为SKU的**默认价格**（新建SKU时自动带入）

### 2. SKU规格价格

位置：商品表单下方「SKU 规格管理」区域

特点：
- 每个SKU可以设置独立的价格
- 支持多规格组合（如：颜色 + 尺寸 = 不同SKU）
- SKU价格会覆盖商品主价格

### 3. 价格优先级规则

```
购买流程中的价格计算：
├── 商品有SKU？
│   ├── 有 → 使用对应SKU的价格
│   └── 无 → 使用商品主价格（price字段）
```

| 场景 | 使用价格 | 说明 |
|------|---------|------|
| 无SKU的单品商品 | 商品主价格 | 简单销售场景 |
| 有SKU的商品 | SKU价格 | 多规格销售，以SKU为准 |
| 有SKU但某个SKU未设置价格 | 商品主价格 | SKU价格为0时降级处理 |

## 实际应用示例

### 示例1：单一规格商品

```
商品名称：iPhone手机
商品价格：¥5999
SKU：无

购买时价格：¥5999
```

### 示例2：多规格商品（服装）

```
商品名称：T恤
商品主价格：¥99

SKU列表：
├── 红色 / S码 → ¥89
├── 红色 / M码 → ¥99
├── 蓝色 / S码 → ¥85
└── 蓝色 / M码 → ¥95

购买选择"红色/M码"→ 价格 ¥99（使用SKU价格）
购买选择"蓝色/S码"→ 价格 ¥85（使用SKU价格）
```

### 示例3：混合场景

```
商品名称：手机壳
商品主价格：¥29

SKU：
├── 型号A → ¥25（比主价格低）
└── 型号B → 未设置价格（使用主价格 ¥29）

购买型号A → ¥25
购买型号B → ¥29
```

## SKU成本价（成本价校验）

位置：SKU规格管理中的「成本价」字段

用途：
- 用于订单改价时的参考
- 改价不能低于成本价（后端校验）
- 帮助商家了解利润空间

---

## 用户购买流程

### 有SKU商品的购买步骤

1. **查看商品详情**
   - 用户进入商品详情页
   - 显示商品主价格（作为参考）

2. **选择规格**
   - 如果商品有多个SKU，显示「规格选择器」
   - 用户需要选择：颜色、尺寸等规格组合
   - 例如：选择「红色 / M码」

3. **确认价格**
   - 选择规格后，价格自动更新为对应SKU的价格
   - 库存也更新为对应SKU的库存

4. **加入购物车或立即购买**
   - 按选中的SKU价格进行结算

### 小程序界面示意

```
商品详情页
├── 图片轮播
├── ¥99（显示的是商品主价格，选规格后更新为SKU价格）
├── 商品名称
├── [颜色：红色 ▼] [尺寸：M码 ▼]  ← 规格选择器
├── 库存：50件
├── [加入购物车] [立即购买]
```

## 设计建议

1. **简单商品（无规格）**：只填写商品主价格，SKU留空
2. **多规格商品**：设置合理的SKU价格，商品主价格作为默认值参考
3. **成本价**：建议填写，方便订单改价时参考
