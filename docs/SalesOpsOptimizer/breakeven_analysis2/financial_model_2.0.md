# 财务模型2.0功能
## 新功能
我在模型变量表中增加了一个父级变量id的字段
parent_id BIGINT COMMENT '父级树ID,标识这个变量属于parent_id的子变量，他的值受父级变量值的约束',
应用举例，
场景1
父级id 对应的变量是毛利润，他的值是金额 数值是10000
他有2个子ID，
集团预留比例 值类型为百分比 数值是40
团队预留比例 值类型为百分比 数值是60
默认的约束条件 集团预留比例*毛利润 + 团队预留比例*毛利润 = 毛利润

场景2
父级id 对应的变量是毛利润，他的值是金额 数值是10000
他有3个子ID，
集团预留比例 值类型为百分比 数值是40
团队预留比例 值类型为百分比 数值是50
定向结余    值类型为金额  数值为1000
默认的约束条件 集团预留比例*毛利润 + 团队预留比例*毛利润 + 定向结余 = 毛利润

场景3
父级id 团队预留比例，他的值是百分比
他有2个子ID，
项目中参与部门的计提比例 值类型为百分比 数值是30
项目中参与员工的计提比例 值类型为百分比 数值是70
默认的约束条件是 项目中参与部门的计提比例 + 项目中参与员工的计提比例 = 100
项目中参与部门的计提比例最后计算的金额值 =通过父级id变量转化后的金额*部门的计提比例

前端展示方式：分成2个展示方式
1、列表展示-就目前的变量列表按排序展示
2、变量树展示-类似于思维导图-编辑和展示都基于当前界面
左侧为根节点，点击+创建子节点 填写配置节点类型
