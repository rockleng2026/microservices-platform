## 🐛 常见问题处理

### 1. 部门树不显示
- **可能原因**: API接口未连接或返回数据格式不正确
- **检查方法**: 打开浏览器控制台查看网络请求和错误日志
- **解决方案**: 确认后端服务运行正常，检查代理配置

### 2. 表单提交失败
- **可能原因**: 表单验证失败或API接口问题
- **检查方法**: 查看控制台错误信息和网络请求
- **解决方案**: 检查必填字段，确认API接口正常

### 3. 样式显示异常
- **可能原因**: CSS样式冲突或Ant Design版本问题
- **检查方法**: 检查浏览器开发者工具中的样式
- **解决方案**: 清除浏览器缓存，检查CSS加载

### 4. 控制台警告信息
- **Modal visible属性警告**: 已修复，使用open属性
- **Form实例警告**: 已优化表单初始化逻辑
- **其他Ant Design组件警告**: 可忽略，不影响功能
