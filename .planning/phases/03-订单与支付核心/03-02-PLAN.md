Redis keys:

  - order:stock:lock:{orderId}  -> pre-allocation record {skuId: quantity, ...}

<!-- IStockService interface -->
public interface IStockService {
    // Pre-allocate stock at order time (STOCK-01)
    // Returns true if all SKUs have sufficient stock
    // Uses Redis DECRBY - if result < 0, INCRBY rollback and return false
    boolean preAllocateStock(Long orderId, List<Map<String, Object>> items);

    // Real stock deduction after payment (STOCK-02)
    // Updates MallGoodsSku.stock in database
    // Writes MallStockLog with operationType=2
    void deductRealStock(Long orderId);

    // Release pre-allocated stock on cancel/timeout (STOCK-03)
    // Uses Redis INCRBY to restore stock
    // Deletes order:stock:lock:{orderId}
    void releaseStock(Long orderId);

    // Manual stock correction by admin (STOCK-05)
    boolean correctStock(Long skuId, Integer change, String operator, String remark);

    // Get current stock for a SKU
    Integer getCurrentStock(Long skuId);

    // Check if stock is below threshold (STOCK-06)
    boolean isBelowThreshold(Long skuId);
}

<!-- IOrderService interface -->
public interface IOrderService extends IService<MallOrder> {
    // Create order from cart items or direct buy (ORDER-01, ORDER-02)
    // 1. Validates address (required for physical goods)
    // 2. Calls StockService.preAllocateStock
    // 3. Creates MallOrder record (status=1 pending pay)
    // 4. Creates MallOrderItem records
    // Returns orderId
    Long createOrder(Long userId, CreateOrderDTO dto);

    // Get user order list (ORDER-03)
    List<MallOrder> getOrderList(Long userId, Integer status);

    // Get order detail with items and delivery info (ORDER-04)
    Map<String, Object> getOrderDetail(Long orderId, Long userId);

    // Cancel order - only pending pay status (ORDER-05)
    boolean cancelOrder(Long orderId, Long userId);

    // Confirm receipt (ORDER-06)
    boolean confirmReceipt(Long orderId, Long userId);

    // Admin: ship order (ORDER-08)
    boolean shipOrder(Long orderId, String expressCode, String expressName, String waybillNo);

    // Update order status after payment (PAY-03)
    // For virtual goods: directly set status=4 and generate delivery record (PAY-04, ORDER-09)
    boolean updateOrderPaid(Long orderId);

    // Handle order timeout (STOCK-03)
    void handleOrderTimeout(Long orderId);
}

<!-- IPayService interface -->
public interface IPayService {
    // Initiate WeChat JSAPI payment (PAY-01)
    // 1. Call WeChat unified order API
    // 2. Get prepay_id
    // 3. Return payment params {timeStamp, nonceStr, package, signType, paySign}
    Map<String, String> initiatePay(Long orderId, String openId);

    // Process WeChat payment callback (PAY-02)
    // 1. Verify signature
    // 2. Update order status
    // 3. Deduct real stock
    // 4. For virtual goods: generate delivery record
    boolean processPayCallback(String xmlData);

    // Query payment status
    String queryPayStatus(Long orderId);
}

    - Inject MallGoodsSkuMapper, MallStockLogMapper
    
    preAllocateStock implementation (STOCK-01):
    - For each item: Long stock = redisTemplate.opsForValue().decrement("sku:stock:" + skuId, quantity)
    - If stock < 0: redisTemplate.opsForValue().increment("sku:stock:" + skuId, quantity) to rollback, return false
    - If stock >= 0: store pre-allocation in Redis hash "order:stock:lock:" + orderId with {skuId: quantity}
    - Write MallStockLog with operationType=1 (pre-allocate)
    
    releaseStock implementation (STOCK-03):
    - Read pre-allocation from "order:stock:lock:" + orderId
    - For each skuId/quantity: redisTemplate.opsForValue().increment("sku:stock:" + skuId, quantity)
    - Delete "order:stock:lock:" + orderId
    - Write MallStockLog with operationType=3 (release)
    
    deductRealStock implementation (STOCK-02):
    - Read pre-allocation from "order:stock:lock:" + orderId
    - For each item: MallGoodsSkuMapper.updateStock via SQL "UPDATE mall_goods_sku SET stock = stock - ? WHERE id = ? AND stock >= ?"
    - Write MallStockLog with operationType=2 (real deduction)
    
    correctStock implementation (STOCK-05):
    - Update MallGoodsSku.stock directly
    - Sync to Redis: redisTemplate.opsForValue().set("sku:stock:" + skuId, newStock)
    - Write MallStockLog with operationType=4 (manual correction)
    
    Initialize Redis stock on first access: if key does not exist, load from MallGoodsSku.stock.

    NOTE: For unlimited stock (stock=-1), skip Redis operations and return true immediately.
  </action>
