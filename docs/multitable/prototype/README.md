# 多维表格系统静态原型页面

本目录包含了多维表格系统的静态原型页面，基于产品需求文档（PRD）和数据库设计方案创建。

## 页面列表

### 1. 首页 (`index.html`)
- **功能**：系统主入口页面
- **特性**：
  - 工作区选择和导航
  - 快速操作面板（创建表格、导入数据等）
  - 最近使用的表格展示
  - 模板推荐和快速搭建
  - 响应式设计，支持移动端

### 2. 多维表格页面 (`table.html`)
- **功能**：表格数据管理和操作
- **特性**：
  - 多视图支持（表格视图、看板视图、日历视图等）
  - 实时数据展示和编辑
  - 筛选、排序、分组功能
  - 字段管理和配置
  - 工具栏和快捷操作
  - 侧边栏工具面板

### 3. 字段配置界面 (`field-config.html`)
- **功能**：表格字段的详细配置管理
- **特性**：
  - 支持多种字段类型（文本、数字、日期、选项、公式等）
  - 字段属性配置（验证规则、显示设置等）
  - 实时预览功能
  - 关联字段配置
  - 公式编辑器

### 4. 问卷调查表编辑页面 (`form-edit.html`)
- **功能**：拖拽式表单设计器
- **特性**：
  - 组件库（基础组件、选择组件、高级组件）
  - 拖拽式设计界面
  - 实时预览功能
  - 字段属性编辑面板
  - 表单标题和描述编辑
  - 字段工具栏（移动、复制、删除）

### 5. 问卷调查表填写页面 (`form-fill.html`)
- **功能**：用户友好的表单填写界面
- **特性**：
  - 渐进式表单体验
  - 实时进度显示
  - 字段验证和错误提示
  - 响应式设计
  - 交互式评分组件
  - 自动保存功能

## 数据结构映射

这些原型页面基于以下核心数据表设计：

- `mt_user` - 用户管理
- `mt_team` - 团队协作
- `mt_table` - 表格元数据
- `mt_field` - 字段配置
- `mt_view` - 视图管理
- `mt_permission` - 权限控制

## 使用方法

1. 直接在浏览器中打开 `index.html` 开始浏览
2. 点击页面中的链接和按钮体验交互功能
3. 使用开发者工具查看响应式设计效果
4. 可以作为前端开发的设计参考和规范

## 注意事项

- 这些是静态原型页面，数据为模拟数据
- 部分交互功能使用JavaScript模拟实现
- 实际开发时需要集成后端API接口
- 样式和交互可根据实际需求进行调整

## 后续开发建议

1. **组件化**：将通用UI组件抽取为可复用模块
2. **状态管理**：使用Vue/React状态管理工具
3. **路由管理**：实现单页应用路由系统
4. **API集成**：连接后端接口实现数据交互
5. **性能优化**：代码分割、懒加载、缓存策略
6. **测试覆盖**：单元测试、集成测试、E2E测试
