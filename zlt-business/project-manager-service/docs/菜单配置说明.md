# 项目管理、绩效管理、薪酬管理菜单配置说明

├── 项目管理 (100)

## 权限配置规则

### 权限命名规范
- 格式：`模块:功能:操作`
- 示例：`project:list:view`（项目列表查看权限）

### 常用操作权限
- `view` - 查看权限
- `add` - 新增权限
- `edit` - 编辑权限
- `delete` - 删除权限
- `export` - 导出权限
- `import` - 导入权限
- `approve` - 审批权限

## 角色权限建议

### 1. 系统管理员
- 拥有所有模块的所有权限
- 可以配置系统设置和基础数据

### 2. 项目经理
- 项目管理模块：完整权限
- 绩效管理模块：查看和评估权限
- 薪酬管理模块：查看权限

### 3. HR管理员
- 项目管理模块：查看权限
- 绩效管理模块：完整权限
- 薪酬管理模块：完整权限

### 4. 部门主管
- 项目管理模块：查看和管理本部门项目
- 绩效管理模块：评估下属员工绩效
- 薪酬管理模块：查看下属薪资信息

### 5. 普通员工
- 项目管理模块：查看参与的项目
- 绩效管理模块：查看个人绩效和自评
- 薪酬管理模块：查看个人工资条

## 使用说明

### 1. 执行SQL脚本
```bash
# 连接到数据库后执行
mysql -u username -p database_name < project-menu-init.sql
```

### 2. 验证菜单数据
```sql
-- 查看菜单数量
SELECT COUNT(*) FROM menu_page WHERE id BETWEEN 100 AND 309;

-- 查看权限数量  
SELECT COUNT(*) FROM menu_func WHERE menu_page_id BETWEEN 100 AND 309;

-- 查看菜单结构
SELECT id, name, parent_id, link_url FROM menu_page 
WHERE id BETWEEN 100 AND 309 
ORDER BY parent_id, sort_order;
```

### 3. 角色权限分配
```sql
-- 示例：为项目经理角色(ID=2)分配项目管理权限
INSERT INTO sys_role_menu (role_id, menu_id) 
SELECT 2, id FROM menu_page WHERE id BETWEEN 100 AND 106;
```

## 注意事项

1. **ID冲突检查**：执行脚本前请确认ID范围100-309没有被使用
2. **租户隔离**：所有菜单默认属于'default'租户，多租户环境需要调整
3. **图标资源**：确保前端有对应的图标资源文件
4. **路由配置**：前端需要配置对应的路由和组件
5. **权限验证**：后端接口需要添加相应的权限验证注解
