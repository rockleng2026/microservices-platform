<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin API -> Database | All admin endpoints write to mall_* tables; TenantInterceptor enforces tenant isolation |
| External URL in Banner | External URLs from mall_banner.external_url are rendered by frontend; no SSRF risk to this backend |
| AES encrypted settings | mall_settings.setting_value encrypted; only decrypted when needed for payment calls |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | mall_settings | mitigate | AES encryption for sensitive fields (D-11); admin UI masks wx_api_key showing only last 4 chars |
| T-02-02 | Information Disclosure | mall_resource_delivery | mitigate | Token is UUID; expire_time enforced at download endpoint; no PII stored |
| T-02-03 | Denial of Service | Statistics API | accept | Redis cache with 5-min TTL (D-05); no database load on every stat request |
</threat_model>
