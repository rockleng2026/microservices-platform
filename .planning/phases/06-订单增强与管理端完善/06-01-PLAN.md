在 `OrderServiceImpl.java` 中实现上述四个方法：

**adminCloseOrder:**
- 校验 orderId 对应订单存在
- 校验 status == 3（已发货），非则抛异常"仅已发货订单可关闭"
- 使用 Redis 锁 `order:close:{orderId}` 防止并发（幂等）
- 设置 status = 8（已关闭），不退款
- 不回增库存（已发货商品已被用户使用）

**adjustOrderAmount:**
- 校验 orderId 对应订单存在
- 校验 status in (1, 2)，非则抛异常"仅待付款/已付款未发货订单可调整金额"
- adjustAmount <= 0（仅允许减少，不能涨价）
- 计算 newPayAmount = oldPayAmount + adjustAmount
- 校验 newPayAmount >= 0，非则抛异常"调整后金额不能为负"
- 校验 newPayAmount <= totalAmount（原总价，不能超过原价）
- 使用 Redis 锁 `order:adjust:{orderId}` 防止并发
- 更新 payAmount，记录操作日志（who/when/old/new）

**updateUserRemark:**
- 校验订单属于该用户
- 更新 remark 字段

**updateAdminRemark:**
- 校验订单存在
- 更新 adminRemark 字段

@PostMapping("/{id}/close")
@Operation(summary = "管理员关闭订单（ORDER-EXT-01）")
public Result<Boolean> adminCloseOrder(@PathVariable Long id, @RequestBody @Validated CloseOrderDTO dto) {
    // dto包含 reason 字段
    try {
        boolean result = orderService.adminCloseOrder(id, getCurrentAdminId(), dto.getReason());
        return result ? Result.succeed(true, "订单已关闭") : Result.failed("关闭失败");
    } catch (RuntimeException e) {
        return Result.failed(e.getMessage());
    }
}

@PostMapping("/{id}/adjust-amount")
@Operation(summary = "管理员调整订单金额（ORDER-EXT-02）")
public Result<Boolean> adjustOrderAmount(@PathVariable Long id, @RequestBody @Validated AdminAdjustOrderDTO dto) {
    try {
        boolean result = orderService.adjustOrderAmount(id, dto.getAdjustAmount(), dto.getReason(), getCurrentAdminId());
        return result ? Result.succeed(true, "金额调整成功") : Result.failed("调整失败");
    } catch (RuntimeException e) {
        return Result.failed(e.getMessage());
    }
}

@PostMapping("/{id}/admin-remark")
@Operation(summary = "管理员添加订单备注（ORDER-EXT-03）")
public Result<Boolean> updateAdminRemark(@PathVariable Long id, @RequestBody @Validated UpdateRemarkDTO dto) {
    try {
        boolean result = orderService.updateAdminRemark(id, dto.getRemark());
        return result ? Result.succeed(true, "备注添加成功") : Result.failed("添加失败");
    } catch (RuntimeException e) {
        return Result.failed(e.getMessage());
    }
}
