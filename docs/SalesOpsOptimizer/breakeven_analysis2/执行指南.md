## 故障排除

### 常见问题

1. **外键约束错误**
   - 确保按正确顺序插入数据
   - 检查 `financial_model_id` 引用是否正确

2. **数据重复错误**
   - 检查是否需要先清理现有数据
   - 确认主键或唯一约束字段

3. **权限错误**
   - 确保数据库用户有INSERT权限
   - 检查表的写入权限

4. **字段不存在错误**
   - 确认表结构是否已正确创建
   - 检查字段名是否匹配

### 数据修复

如果数据有问题，可以：

1. **删除特定模型数据**
```sql
DELETE FROM soo_model_variable WHERE financial_model_id = 1;
DELETE FROM soo_financial_model WHERE id = 1;
```

2. **重新插入特定数据**
   选择 `init_data.sql` 中相应的INSERT语句重新执行
