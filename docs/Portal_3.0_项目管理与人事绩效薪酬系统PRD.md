# Portal 3.0 项目管理与人事绩效薪酬系统PRD

## 1. 项目背景与目标

### 1.1 项目背景
基于现有Portal 3.0微服务架构，开发人事绩效考核管理模块和项目薪酬激励系统，旨在通过科学的绩效评估和丰厚的激励政策提高员工工作积极性和创收能力。

### 1.2 项目目标
- **激励机制优化**：从基础工资+绩效工资扩展为基础工资+绩效工资+项目提成+部门分红
- **全员激励**：不仅销售员工，其他部门员工为公司提供商机、参与项目都给予相应奖励
- **科学分配**：基于项目毛利润进行分成，50%用于项目参与人员分红，30%用于部门分红，20%作为公司发展资金
- **流程规范**：集成Flowable工作流引擎，确保绩效考核和薪酬分配的审批流程化

### 1.3 业务规则核心要点
1. **项目提成**：基于项目毛利润50%进行人员分红
2. **部门分红**：项目毛利润30%用于部门分红，前提是部门年度业绩达标
3. **分红发放**：项目提成在回款后3个月内发放，部门分红在年度审核后发放
4. **考核等级**：绩效评级采用S、A、B、C、D五级制度
5. **风险控制**：大额奖金分阶段兑现，防止员工兑现后离职

## 3. 核心业务流程

### 3.1 项目管理流程
```
项目立项 → 团队组建 → 毛利分配方案制定 → 项目执行 → 进度跟踪 → 项目结项 → 分成发放
```

### 3.2 绩效考核流程
```
目标制定 → 目标审批 → 执行期管理 → 自我评价 → 领导评价 → 人事审核 → 结果确认 → 绩效工资发放
```

### 3.3 薪酬分配流程
```
项目收益确认 → 毛利润计算 → 分配方案审批 → 项目提成发放 → 部门分红核算 → 年终奖分配
```

## 5. 关键业务规则

### 5.1 项目分红逻辑
1. **项目毛利润分配**：
   - 50% 用于项目参与人员分红
   - 30% 用于部门分红（需要部门达标）
   - 20% 作为公司发展资金

2. **部门分红系数**：
   - 4个考核指标全达标：系数 1.0
   - 3个达标：系数 0.9
   - 2个达标：系数 0.7
   - 1个达标：系数 0.6
   - 0个达标：保底分红（需申请）

### 5.2 绩效工资发放规则
- 绩效工资与当月项目回款挂钩
- 绩效达标全额发放，不达标则无绩效工资
- 后续项目提成也按实际回款计算

### 5.3 风险控制机制
- 大额项目提成分阶段兑现
- 部门分红在年度审核后统一发放
- 分红分配需要多级审批确认
