# Phase 10 — UI Design Contract

> Visual and interaction contract for Phase 10: 管理后台核心模块 (商品管理、订单管理、优惠券管理、轮播图管理). Generated by gsd-ui-researcher.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Ant Design Pro only) |
| Preset | not applicable |
| Component library | Ant Design 4 (ProTable, Modal, Form, Tabs, Upload, Switch) |
| Icon library | @ant-design/icons |
| Font | -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto (inherited from Phase 8) |

**Design inheritance:** All tokens inherit from Phase 8 (08-UI-SPEC.md). Only new tokens specific to Phase 10 modules are declared below.

---

## Spacing Scale

Inherited from Phase 8 (8-point grid):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, table cell padding |
| md | 16px | Default element spacing, form item margin |
| lg | 24px | Section padding, card padding |
| xl | 32px | Layout gaps, modal header |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

**Phase 10 exceptions:**
- ProTable cell padding: 12px 16px (compact but readable)
- Banner list drag handle: 8px horizontal gap
- Order detail sections: 24px vertical spacing between cards

---

## Typography

**Phase 10 uses 4 distinct sizes (max 4 per spec):**

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| H1 | 32px | 700 (bold) | 1.2 | Page titles (商品管理, 订单管理, etc.) |
| H2 | 24px | 600 (semibold) | 1.3 | Section headings within pages |
| Body/Price | 16px | 400/600 | 1.5 | Body text (400), prices/emphasis (600) |
| Label | 14px | 400 | 1.5 | Form labels, table content, ProTable text |

**System-level elements (inherit from Ant Design defaults):**
- Status badges, captions, hints: 12px (antd default)
- These are not separately declared as they use antd system styles

---

## Color

Inherited from Phase 8:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #f5f5f5 | Page background |
| Secondary (30%) | #ffffff | Cards, sidebar, header, modals |
| Accent (10%) | #1890ff | Primary buttons, links, active states |
| Accent Hover | #40a9ff | Hover states |
| Destructive | #ff4d4f | Delete, reject, close, cancel actions |

**Phase 10 explicit accent reservations:**
- Accent (#1890ff) reserved for: Primary CTAs (Create, Save, Publish), active tabs, links, ProTable search highlight
- Destructive (#ff4d4f) reserved for: Delete product, close order, reject refund, batch delete

**Module-specific status colors (ProTable valueEnum):**

| Status | Color | Usage |
|--------|-------|-------|
| 上架 / 发放中 / 已完成 | Success (#52c41a) | ProTable status badge |
| 下架 / 已取消 / 禁用 | Default (#d9d9d9) | ProTable status badge |
| 待付款 / 待发货 | Warning (#faad14) | ProTable status badge |
| 已付款 / 已发货 | Processing (#1890ff) | ProTable status badge |
| 已过期 | Error (#ff4d4f) | ProTable status badge |

## Interaction Patterns

| Interaction | Behavior |
|-------------|----------|
| Batch select | rowSelection + selectedRowKeys, toolbar buttons enable when length > 0 |
| Batch publish/unpublish | Modal.confirm with count, then PUT /batch/status |
| Product edit Modal | Opens on "Create" or "Edit" click, form pre-filled for edit |
| Image drag-sort | @dnd-kit/sortable on preview list, order saved on submit |
| Banner drag-sort | Sequential PUT /{id}/sort/{sort} after drag end |
| Order tab filter | Tabs component, re-queries ProTable on tab change |
| Order price edit | Inline InputNumber, shows delta on change, optional reason |
| Close order | Modal with Select reason + optional TextArea |
| Ship order | Modal with express inputs |
| Coupon publish/offline | Row button + Modal.confirm |
| Banner enable/disable | Switch component + PUT /banner |

## State Handling

| State | Handling |
