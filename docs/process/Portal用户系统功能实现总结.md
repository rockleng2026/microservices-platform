# Portal用户系统功能实现总结

## 概述

基于您的需求，我们完成了Portal系统的用户信息接口实现，包含了完整的权限系统和个性化配置功能。该实现参考了SysUserController的设计模式，提供了企业级的用户管理解决方案。

## 核心功能

### 1. 用户信息管理
- **获取当前用户信息**：`GET /api-portal/users/current`
- **用户登录认证**：支持用户名、手机号、用户ID多种方式查询
- **用户基本信息**：包含用户名、昵称、头像、联系方式等

### 2. 组织架构体系
- **部门管理**：支持多级部门结构
- **岗位管理**：岗位与部门关联，支持权限配置
- **员工管理**：员工与用户关联，支持多岗位
- **权限继承**：基于岗位的权限体系

### 3. 权限系统
- **基于岗位的权限控制**：用户通过岗位获得菜单和功能权限
- **菜单权限树**：支持多级菜单结构和权限继承
- **功能权限**：每个菜单支持细粒度的功能权限控制
- **动态权限加载**：根据用户当前岗位动态加载权限

### 4. 个性化配置
- **默认岗位设置**：多岗位用户可设置默认登录岗位
- **主题配置**：支持浅色、深色、自动跟随系统
- **语言设置**：支持多语言切换
- **布局配置**：个性化界面布局设置
- **通知配置**：个性化通知偏好设置

### 5. 岗位切换
- **动态岗位切换**：用户可在多个岗位间切换
- **权限实时更新**：切换岗位后权限实时生效
- **配置自动更新**：切换后自动更新个性化配置

## 技术架构

### 数据库设计

#### 核心表结构
1. **users** - 用户表：存储用户基本信息和登录凭证
2. **employee** - 员工表：存储员工详细信息，关联用户和岗位
3. **department** - 部门表：支持多级部门结构
4. **workposition** - 岗位表：存储岗位信息和权限配置
5. **menu** - 菜单表：支持多级菜单结构
6. **menu_function** - 菜单功能权限表：细粒度功能权限
7. **user_personal_config** - 用户个性化配置表：存储用户偏好设置

#### 关联关系
```
用户(users) → 员工(employee) → 岗位(workposition) → 权限(menu/menu_function)
用户(users) → 个性化配置(user_personal_config)
```

### 服务层设计

#### PortalUserService接口
- `getCurrentUserInfo()` - 获取用户完整信息
- `getUserPositions()` - 获取用户岗位列表
- `getCurrentUserMenus()` - 获取用户菜单权限
- `switchUserPosition()` - 切换用户岗位
- `getUserPersonalConfig()` - 获取个性化配置
- `saveUserPersonalConfig()` - 保存个性化配置
- `updateDefaultPosition()` - 更新默认岗位

#### MenuPermissionService接口
- `getCurrentUserMenus()` - 获取用户菜单权限
- `getMenusByPositionId()` - 根据岗位获取菜单权限
- `buildMenuTree()` - 构建菜单权限树

### API接口设计

#### 用户信息接口
```http
GET /api-portal/users/current
```
**响应数据结构：**
```json
{
  "user": {}, // 用户基本信息
  "employee": {}, // 员工信息（含部门）
  "positions": [], // 用户所有岗位
  "currentPosition": {}, // 当前生效岗位
  "menus": [], // 菜单权限树
  "personalConfig": {}, // 个性化配置
  "tenant": {} // 租户信息
}
```

#### 其他核心接口
- `GET /users/positions` - 获取岗位列表
- `GET /users/menus` - 获取菜单权限
- `GET /users/personal-config` - 获取个性化配置
- `POST /users/personal-config` - 保存个性化配置
- `POST /users/switch-position` - 切换岗位
- `POST /users/default-position` - 更新默认岗位

## 实现特色

### 1. 企业级权限模型
- **多维度权限控制**：用户→员工→岗位→权限的完整链路

- **动态权限加载**：实时计算和加载用户权限

### 3. 完善的个性化配置
- **主题定制**：支持多种主题模式
- **布局个性化**：可自定义界面布局
- **语言国际化**：支持多语言环境
- **通知偏好**：个性化通知设置

### 4. 高度可扩展性
- **模块化设计**：清晰的服务分层和接口设计
- **配置化权限**：通过配置控制权限，无需修改代码
- **多租户支持**：完整的多租户数据隔离
