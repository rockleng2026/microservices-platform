# Portal 3.0 数据初始化说明

## 概述

本目录包含了Portal 3.0微服务平台的数据库初始化脚本，用于创建完整的示例数据。

## 脚本文件

### 1. menu-init.sql
- **作用**: 初始化菜单和功能权限数据
- **内容**: 系统管理模块的菜单结构和功能点权限
- **使用时机**: 在组织模块基础数据导入后执行

### 2. sample-data.sql  
- **作用**: 初始化示例业务数据
- **内容**: 用户、员工、职位和完整的权限关联数据
- **使用时机**: 在菜单数据初始化后执行

## 执行顺序

```bash
# 1. 首先执行组织模块基础表结构
mysql -u root -p portal_db < organization-module.sql

# 2. 然后执行菜单初始化
mysql -u root -p portal_db < menu-init.sql  

# 3. 最后执行示例数据初始化
mysql -u root -p portal_db < sample-data.sql
```

## 扩展说明

### 添加新用户
1. 在 `employee` 表中添加员工信息
2. 在 `users` 表中创建登录账号，关联员工ID
3. 在 `user_role` 表中分配角色权限

### 权限配置
- `role_menu`: 控制菜单可见性
- `role_function`: 控制具体功能权限
- 支持细粒度的按钮级权限控制

### 多租户支持
- 所有表都包含 `tenant_id` 字段
- 数据隔离通过租户ID实现
- 支持租户级别的权限配置
