# Portal 3.0 项目管理与人事绩效薪酬系统原型设计提示词

## 一、设计背景与目标

基于 `@newPortalSalaryAndProject.md` PRD文档和 `@newPortalSalaryAndProject-init.sql` 数据表结构，设计Portal 3.0项目管理与人事绩效薪酬系统的高保真原型界面。

## 二、核心模块与页面要求

### 1. 项目管理模块
- **产品毛利分配规则列表**：表格展示，支持筛选、搜索、状态标识、操作按钮
    新增产品毛利分配规则
    编辑产品毛利分配规则
    删除产品毛利分配规则
- **项目立项页面**：表单式设计，包含项目基本信息、参与人选择、角色分配
- **项目列表页面**：表格展示，支持筛选、搜索、状态标识、操作按钮
- **项目详情页面**：Tab切换设计，包含基本信息、参与人员、进度跟踪、分配方案
- **项目结项页面**：结项信息录入、毛利润计算、提成预览
- **分配管理页面**：可视化分配方案、审批流程状态、调整申请

### 2. 绩效考核模块
- **绩效目标设定页面**：层级式目标设定、标准配置、周期选择
- **绩效考核页面**：考核表单、自评互评、等级选择、评价输入
- **绩效结果页面**：考核结果展示、图表统计、历史对比
- **绩效审批页面**：审批流程可视化、批量审批、意见填写

### 3. 薪酬与分红模块
- **薪酬总览页面**：个人薪酬构成饼图、收入趋势图、分红明细
- **部门分红页面**：储备金账户、分配方案、审批状态
- **分红审批页面**：分红申请列表、审批详情、分阶段发放设置

### 4. 审批流程模块
- **待办任务页面**：任务列表、优先级标识、快速审批
- **审批详情页面**：流程图展示、审批历史、操作按钮
- **流程监控页面**：流程统计、效率分析、异常提醒

## 三、设计规范与要求

### 1. 整体框架
- 基于原工程 `@html` 主体框架进行扩展
- 采用左侧导航 + 顶部面包屑 + 主内容区布局
- 支持响应式设计，适配PC端和移动端

### 2. 视觉设计规范
- **色彩体系**：主色调采用企业蓝（#1890ff），辅助色彩丰富但统一
- **字体规范**：主标题16px，正文14px，辅助文字12px
- **间距规范**：8px基础间距，16px、24px、32px递增
- **组件统一**：统一按钮样式、表单组件、状态标识、图标使用

### 3. 交互体验要求
- **操作便捷**：常用操作不超过3步，支持快捷键和批量操作
- **反馈及时**：加载状态、操作结果、错误提示清晰明确
- **导航清晰**：面包屑导航、页面标题、返回按钮等
- **数据可视化**：重要数据采用图表展示，支持交互筛选

### 4. 表单设计规范
- **分步骤表单**：复杂表单采用分步骤设计，进度条指示
- **智能校验**：实时校验、友好的错误提示、必填项标识
- **数据联动**：部门选择联动岗位、员工选择等
- **保存机制**：支持草稿保存、自动保存、历史版本

### 5. 列表与表格设计
- **高效筛选**：多条件筛选、快速筛选标签、搜索建议
- **批量操作**：支持多选、批量审批、批量导出
- **分页与加载**：合理分页、虚拟滚动、无限加载
- **状态标识**：清晰的状态标签、进度条、操作按钮

## 四、特殊功能设计要求

### 1. 审批流程可视化
- 流程图展示当前节点、已完成节点、待处理节点
- 审批历史时间线展示
- 支持流程跳转、驳回、加签等操作

### 2. 数据统计与图表
- 项目收益分析图表（柱状图、饼图、趋势图）
- 绩效分布统计（雷达图、热力图）
- 薪酬构成分析（堆叠柱状图、环形图）

### 3. 权限控制界面
- 不同角色显示不同操作按钮
- 数据权限控制（只显示有权限的数据）
- 功能权限提示（无权限时的友好提示）

### 4. 多租户支持
- 租户切换组件
- 租户数据隔离界面体现
- 租户配置管理界面

## 五、技术实现要求

### 1. 代码规范
- 使用HTML5 + CSS3 + 原子化CSS
- 推荐使用Ant Design、Element Plus等成熟UI框架
- 保持代码结构清晰、注释完整

### 2. 性能优化
- 图片懒加载、代码分割
- 合理使用缓存策略
- 优化首屏加载时间

### 3. 兼容性要求
- 支持主流浏览器（Chrome、Firefox、Safari、Edge）
- 移动端适配（响应式设计）
- 支持暗色主题切换

## 八、质量标准

1. **易用性**：新用户能够在5分钟内完成基础操作
2. **一致性**：界面元素、交互模式保持高度一致
3. **效率性**：常用操作路径最短，支持快捷操作
4. **美观性**：界面现代化、专业化，符合企业级产品标准
5. **扩展性**：设计方案具备良好的扩展性和维护性
