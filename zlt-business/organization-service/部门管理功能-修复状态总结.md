## 数据库修复

如果gradeId字段仍然为空，执行修复脚本：

```sql
-- 更新空的grade_id字段
UPDATE department 
SET grade_id = level 
WHERE grade_id IS NULL 
  AND level IS NOT NULL 
  AND delflag = 0;

-- 验证修复结果
SELECT id, name, grade_id, level 
FROM department 
WHERE delflag = 0 
  AND (grade_id IS NULL OR grade_id != level);
```
