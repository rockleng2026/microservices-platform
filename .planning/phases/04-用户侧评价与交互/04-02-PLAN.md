    - Left join or subquery to get orderCount and totalConsumption per userId
    - Support keyword filter on nickname or phone
    - Map to UserListDTO with orderCount and totalConsumption

    getUserStatistics (USER-05):
    - Query sys_user by userId
    - Aggregate mall_order: count(*), sum(payAmount) where userId = userId and status >= 2
    - Build UserStatisticsVO with all stats

    Note: Multi-tenancy - sys_user has tenantId field. Admin queries bypass tenant filter for all users (admin privilege). Use TenantInterceptor.getCurrentTenantId() only for non-admin mall queries.

    Implementation approach: Use MyBatis-Plus Sqlseletor to execute raw SQL joining two databases:
    SELECT u.id, u.open_id, u.nickname, u.phone, u.create_time,
           COUNT(o.id) as orderCount,
           COALESCE(SUM(CASE WHEN o.status >= 2 THEN o.pay_amount ELSE 0 END), 0) as totalConsumption
    FROM sys_user u
    LEFT JOIN cp_mall.mall_order o ON u.id = o.user_id
    WHERE u.tenant_id = ?
    GROUP BY u.id
    ORDER BY totalConsumption DESC
  </action>
