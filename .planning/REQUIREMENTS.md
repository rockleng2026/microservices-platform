# Mall v2.1 商城使用帮助文档

## Overview

在商场系统管理后台增加「商城使用帮助文档」菜单，下设三个子菜单：接口文档、菜单使用说明、FAQ。便于开发人员和业务人员快速上手使用。

**数据库：** root/lengfeng847
**后端服务：** mall-center（端口 7010）
**前端框架：** React + Umi + Ant Design（与 portal-web 一致）

---

## Active Requirements

### HELP-01 接口文档

| ID | Requirement | Priority |
|----|-------------|----------|
| HELP-01-01 | 页面列出 mall-center 所有 Controller 接口（商品、订单、购物车、用户、优惠券、评价等） | P0 |
| HELP-01-02 | 每个接口显示：接口路径、请求方法、请求参数、响应格式、业务逻辑说明 | P0 |
| HELP-01-03 | 支持按模块分类浏览和搜索接口 | P1 |
| HELP-01-04 | 接口文档数据可配置，存储在数据库或 JSON 文件中 | P1 |

### HELP-02 菜单使用说明

| ID | Requirement | Priority |
|----|-------------|----------|
| HELP-02-01 | 页面列出商城所有功能模块（商品管理、订单管理、优惠券管理、物流管理等） | P0 |
| HELP-02-02 | 每个功能模块包含：功能描述、操作步骤、注意事项、截图指引 | P0 |
| HELP-02-03 | 支持按模块分类浏览和搜索 | P1 |
| HELP-02-04 | 内容面向业务人员和前端开发人员，文字简洁易懂 | P1 |

### HELP-03 FAQ

| ID | Requirement | Priority |
|----|-------------|----------|
| HELP-03-01 | 页面列出常见问题（开发问题、业务问题、配置问题等） | P0 |
| HELP-03-02 | 每个 FAQ 包含：问题描述、原因分析、解决方案、相关链接 | P0 |
| HELP-03-03 | 支持按分类浏览（开发类、业务类、配置类、常见错误） | P1 |
| HELP-03-04 | FAQ 数据可扩展，便于后续新增 | P1 |

## Out of Scope

- 视频教程或动画演示 — 文字+截图足够
- 打印或导出 PDF 功能 — 后续迭代
- 多语言版本 — 中文版优先
