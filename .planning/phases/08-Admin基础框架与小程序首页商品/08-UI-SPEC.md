## Layout Structure

### Admin Web — Dashboard (ADMIN-01)

```
+----------------------------------------------------------+
| [Sidebar 240px]  |  [Header 60px]                        |
|                  +----------------------------------------+
|  Logo + Nav     |  Breadcrumb + Search + Notifications   |
|                  +----------------------------------------+
|                  |  [Content Area]                       |
|                  |                                        |
|                  |  +----------------------------------+  |
|                  |  | Welcome Banner (gradient blue)   |  |
|                  |  +----------------------------------+  |
|                  |                                        |
|                  |  +-------+ +-------+ +-------+ +------+|
|                  |  |Metric1| |Metric2| |Metric3| |Metr4 ||  (Key Metrics)
|                  |  +-------+ +-------+ +-------+ +------+|
|                  |                                        |
|                  |  +------------------+ +-------------+  |
|                  |  | Sales Trend Chart| |Low Stock    |  |
|                  |  | (ECharts line)   | |Alerts List  |  |
|                  |  +------------------+ +-------------+  |
|                  |                                        |
|                  |  +------------------+ +-------------+  |
|                  |  | User Stats       | |Top Products|  |
|                  |  | (new + active)   | |Ranking     |  |
|                  |  +------------------+ +-------------+  |
|                  |                                        |
+------------------+----------------------------------------+
```

**Key Layout Rules:**
- Sidebar: 240px fixed width, white background, border-right 1px #e8e8e8
- Header: 60px height, sticky top, shadow
- Content: 24px padding, #f5f5f5 background
- Cards: 12px border-radius, 2px shadow, white background
- Grid: 24px gap between cards

## Interaction Patterns

### Admin Web

| Interaction | Behavior |
|-------------|----------|
| Hover states | Card: translateY(-2px), shadow increase |
| Table row hover | #f5f5f5 background |
| Button hover | Color lighten 10% |
| Menu item hover | #f0f9ff background |
| Menu item selected | #e6f7ff background, #1890ff left border |
| Chart tooltips | Dark background, white text |
| Loading | Skeleton placeholders for cards |

### Mini Program

| Interaction | Behavior |
|-------------|----------|
| Pull-to-refresh | Native scroll refresh |
| Infinite scroll | Load more at 80% scroll position |
| Swipe carousel | Touch swipe, auto-play 3s interval |
| Tap spec button | Toggle select, update price |
| Quantity stepper | Long press for rapid change |
| Tab bar | Tap switches, no animation |
| Product card tap | Navigate to detail page |
| Add to cart | Success toast "已加入购物车" |

## State Handling

### Admin Web

| State | Handling |
|-------|----------|
| Loading | Skeleton screens matching card layout |
| Empty | Centered illustration + "暂无数据" message |
| Error | Inline error message with retry button |
| Success | Auto-dismiss notification after 3s |

### Mini Program

| State | Handling |
|-------|----------|
| Loading | Skeleton shimmer for product cards |
| Empty | Centered illustration + message |
| Error | "网络开小差了" with refresh button |
| Pull-to-refresh | Native behavior |
| Add to cart success | Toast: "已加入购物车" |
| Add to cart fail | Toast: "加入失败，请重试" |
