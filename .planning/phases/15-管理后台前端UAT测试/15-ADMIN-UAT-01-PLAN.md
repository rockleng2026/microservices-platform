# Phase 15 Plan: 管理后台前端UAT测试

## 目标
对迁移到 portal-web 的管理后台页面进行完整的UAT测试，验证所有商城管理功能页面正常工作。

## 背景
Phase 14 已完成 mall-admin-web 到 portal-web 的前端迁移。Phase 8 的 UAT 仅测试了后端 API，现在需要补充前端页面功能的完整测试。

## 任务分解

### ADMIN-UAT-01-01: Dashboard 工作台测试
**描述**: 验证 Dashboard 页面正常加载，数据正确显示

**执行步骤**:
1. 启动 portal-web: `cd zlt-web/portal-web && npm run dev`
2. 使用管理员账号登录
3. 访问 Dashboard: http://localhost:8001/mall-admin/dashboard
4. 验证页面加载无报错
5. 验证统计卡片数据（非0或loading状态）
6. 验证销售趋势图表正常渲染
7. 验证库存预警列表显示
8. 验证热销排行显示

**验证**: Dashboard 页面所有组件正常显示数据

---
