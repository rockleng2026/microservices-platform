  <name>Task 1: Create OrderController with user order endpoints</name>
  <files>
    - "zlt-business/mall-center/src/main/java/com/central/mall/controller/OrderController.java"
  </files>
  <action>
    Create OrderController.java following CartController pattern:
    - @RestController, @RequestMapping("/api/mall/order"), @RequiredArgsConstructor
    - @Tag(name = "订单管理", description = "小程序端订单接口")
    - Inject IOrderService, IPayService
    - getCurrentUserId() returns 1L stub (same as CartController)

    Endpoints:
    1. POST / (createOrder) - ORDER-01, ORDER-02
       - @RequestBody CreateOrderDTO dto
       - Validates goodsType required
       - If goodsType=1: validates addressId required
       - Validates (cartItemIds not empty OR items not empty)
       - Calls orderService.createOrder(userId, dto)
       - Returns Result.succeed(orderId)

    2. GET / (getOrderList) - ORDER-03
       - @RequestParam(required = false) Integer status
       - Calls orderService.getOrderList(userId, status)
       - Returns Result.succeed(list)

    3. GET /{id} (getOrderDetail) - ORDER-04
       - @PathVariable Long id
       - Calls orderService.getOrderDetail(id, userId)
       - Returns Result.succeed(detail) or Result.failed("订单不存在")

    4. DELETE /{id} (cancelOrder) - ORDER-05
       - @PathVariable Long id
       - Only status=1 can be cancelled
       - Calls orderService.cancelOrder(id, userId)
       - Returns Result.succeed(true) or Result.failed("取消失败")

    5. PUT /{id}/confirm (confirmReceipt) - ORDER-06
       - @PathVariable Long id
       - Only status=3 (shipped) can be confirmed
       - Calls orderService.confirmReceipt(id, userId)
       - Returns Result.succeed(true) or Result.failed("确认收货失败")

    6. POST /{id}/pay (initiatePay) - PAY-01
       - @PathVariable Long id
       - @RequestParam String openId (from mini-program)
       - Calls payService.initiatePay(id, openId)
       - Returns Result.succeed(paymentParams) with {timeStamp, nonceStr, package, signType, paySign}

    Validation:
    - Use Result.failed() for all error cases (not exceptions)
    - Return appropriate HTTP status codes (200 for success, 400 for bad request)
  </action>

    <automated>grep -c "createOrder\|getOrderList\|getOrderDetail\|cancelOrder\|confirmReceipt\|initiatePay" zlt-business/mall-center/src/main/java/com/central/mall/controller/OrderController.java</automated>
  </verify>
  <done>OrderController has all 6 endpoints following CartController patterns. Each endpoint validates input and returns Result.succeed/failed.</done>
